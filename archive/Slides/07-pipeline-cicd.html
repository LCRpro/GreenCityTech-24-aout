Point de méthode

Les contrôles rapides de pull request ne couvrent pas le même besoin que les tests avancés. Les E2E exigent souvent un environnement cohérent, une base de test et des artefacts déjà construits.

Chaîne mobile

Le mobile n’est pas industrialisé au même niveau que le web/backend au démarrage : tests unitaires, build de validation si possible, puis recette manuelle structurée.
