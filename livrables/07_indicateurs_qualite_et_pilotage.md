# Indicateurs qualité et pilotage

## Objectif

Définir un jeu réduit mais utile d'indicateurs pour piloter la transformation.

## Principe

Il vaut mieux peu d'indicateurs, suivis régulièrement, qu'un tableau de bord trop chargé et inutilisé.

## Indicateurs DevOps

- fréquence de déploiement ;
- lead time ;
- taux d'échec des déploiements ;
- MTTR.

## Indicateurs qualité

- bugs détectés en production ;
- taux de réussite des pipelines ;
- couverture de tests ;
- régressions sur parcours critiques.

## Indicateurs exploitation

- disponibilité du portail et de l'API ;
- temps moyen de réponse API ;
- nombre d'alertes critiques ;
- temps moyen de traitement d'une alerte.

## Indicateurs sécurité / conformité

- vulnérabilités critiques ouvertes ;
- incidents liés aux secrets ou aux accès ;
- taux d'échec d'upload photo ;
- anomalies d'accessibilité détectées.

## Indicateurs produit et collectivités

- satisfaction des collectivités ;
- nombre de demandes en attente ;
- délai de qualification des évolutions ;
- volume de signalements traités.

## Indicateurs prioritaires à retenir à l'oral

- fréquence de déploiement ;
- taux d'échec des déploiements ;
- bugs en production ;
- disponibilité ;
- temps de réponse API ;
- vulnérabilités critiques ouvertes ;
- satisfaction des collectivités.
